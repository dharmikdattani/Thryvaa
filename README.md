## Installation

### Prerequisites
- Node.js (version 20.10.0 or higher)
- npm (version 10.2.3 or higher)

### Clone the repository
```sh
git clone https://github.com/CrestParth/Pobo-BE-API.git
cd Pobo-BE-API
```

### Install dependencies
```sh
npm install
```

## Usage

### Running the server
To start the server in development mode:
```sh
npm run dev
```

To start the server in production mode:
```sh
npm start
```

### Accessing the server
The server will be running at `http://localhost:5009` by default. You can access the API endpoints using a tool like Postman or your browser.
